# Аватары для Telegram с полным дизайном

Профессиональные варианты аватара с логотипами платформ, названием и текстом для Telegram.

## Варианты:

### 1. **avatar-telegram-pro.svg** ⭐ РЕКОМЕНДУЕТСЯ
- Чистый B2B стиль
- Белый фон с выделенной верхней секцией
- Крупные, читаемые логотипы платформ
- Крупное название Leadspikers
- Толстая оранжевая линия
- Четкий текст описания
- **Лучший выбор для B2B**

### 2. **avatar-telegram-full.svg**
- Базовый вариант
- Все элементы на белом фоне
- Стандартные размеры
- Хорошая читаемость

### 3. **avatar-telegram-minimal.svg**
- Минималистичный стиль
- Логотипы платформ в виде кругов с буквами/символами
- Компактное расположение
- Для тех, кто предпочитает минимализм

### 4. **avatar-telegram-premium.svg**
- Премиум вариант
- Эффекты теней
- Более выразительный градиент
- Крупные элементы
- Для премиум позиционирования

## Элементы дизайна:

- **Логотипы платформ**: Gmail, Telegram, LinkedIn, Outlook
- **Название**: Leadspikers (крупный шрифт, 72-84px)
- **Оранжевая линия**: Градиент под названием
- **Текст**: "Аутрич, который работает: эффективное привлечение В2В-клиентов"

## Как использовать:

1. Откройте SVG в браузере (Chrome/Firefox)
2. Сделайте скриншот или экспортируйте в PNG:
   - Размер: 512x512 или 640x640 пикселей
   - Формат: PNG
3. Загрузите в Telegram как аватарку

## Рекомендация:

Для B2B лучше использовать **avatar-telegram-pro.svg** - он выглядит профессионально, все элементы читаются, соответствует стилю сайта.

## Технические детали:

- Шрифт: Inter (900 weight для названия, 600-700 для текста)
- Цвета: Оранжевый градиент (#FF4D00 → #FF6B2C)
- Фон: Белый (#FFFFFF) или светло-серый (#FAFAFA)
- Размеры: Оптимизированы для Telegram аватарки
