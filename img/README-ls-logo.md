# Логотипы LS для Telegram

Профессиональные варианты логотипа с буквами "LS" для Telegram аватарки в B2B стиле.

## Варианты:

### 1. **logo-ls-telegram-pro.svg** ⭐ РЕКОМЕНДУЕТСЯ
- Круглый формат
- Оранжевый градиентный круг с тенью
- Крупные буквы LS
- Акцентная линия под буквами
- **Лучший выбор для B2B**

### 2. **logo-ls-telegram-square.svg**
- Скругленный квадрат
- Современный минималистичный стиль
- Крупные буквы LS
- Подходит для более строгого корпоративного стиля

### 3. **logo-ls-telegram-clean.svg**
- Чистый минимализм
- Светлый фон (#FAFAFA)
- Максимально простой дизайн
- Для тех, кто предпочитает минимализм

### 4. **logo-ls-telegram-premium.svg**
- Премиум вариант с эффектом свечения
- Дополнительная глубина за счет внутреннего круга
- Более выразительный градиент
- Для премиум позиционирования

## Как использовать:

1. Откройте SVG в браузере (Chrome/Firefox)
2. Сделайте скриншот или экспортируйте в PNG:
   - Размер: 512x512 или 640x640 пикселей
   - Формат: PNG с прозрачным фоном (если нужно)
3. Загрузите в Telegram как аватарку

## Рекомендация:

Для B2B лучше использовать **logo-ls-telegram-pro.svg** - он выглядит профессионально, читается в маленьком размере и соответствует стилю сайта.

## Технические детали:

- Шрифт: Inter (900 weight)
- Цвета: Оранжевый градиент (#FF4D00 → #FF6B2C)
- Фон: Белый (#FFFFFF) или светло-серый (#FAFAFA)
- Letter-spacing: -0.1em до -0.15em (компактный вид)
