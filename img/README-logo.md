# Логотипы для Telegram аватарки

Создано 3 варианта логотипа в стиле сайта Leadspikers:

## Варианты:

1. **logo-telegram-avatar.svg** - Полный вариант с текстом "Leadspikers"
   - Размер: 512x512
   - Белый фон, оранжевый градиентный круг, белая молния
   - Включает название компании

2. **logo-telegram-icon-only.svg** - Только иконка (рекомендуется)
   - Размер: 512x512
   - Белый фон, оранжевый градиентный круг с тенью, белая молния
   - Без текста - лучше читается в маленьком размере

3. **logo-telegram-minimal.svg** - Минималистичный вариант
   - Размер: 512x512
   - Светло-серый фон (#FAFAFA), оранжевый круг, белая молния
   - Самый чистый вариант

## Как использовать:

1. Откройте SVG файл в браузере или редакторе (Figma, Illustrator, Inkscape)
2. Экспортируйте в PNG 512x512 или 640x640 пикселей
3. Загрузите в Telegram как аватарку

## Рекомендация:

Для Telegram лучше использовать **logo-telegram-icon-only.svg** - он лучше читается в маленьком размере и выглядит профессионально.

## Цвета:

- Оранжевый градиент: #FF4D00 → #FF6B2C
- Белый: #FFFFFF
- Фон: #FFFFFF или #FAFAFA
- Черный текст: #0A0A0A
